# Friendship Lab

A fun and interactive web application that analyzes friendship compatibility between two names. This project started as a simple bond checker and was later redesigned with a modern user interface, animations, dark mode support, and engaging user interactions.

Preview

Friendship Lab allows users to enter two names and receive a friendship compatibility score along with friendship levels, badges, and special surprises.

# Features
<ul>
<li>Friendship compatibility score generation</li>
<li>Live avatar generation from name initials</li>
<li>Friendship levels based on score</li>
<li>Random friendship badges</li>
<li>Loading animation before results<li>
<li>Confetti celebration for high friendship scores</li>
<li>Dark mode support</li>
<li>Responsive design for mobile and desktop</li>
<li>Secret friendship combination → Special 100% result </li> 
<li>Interactive and modern UI design</li>

# How It Works
Enter two names.
Click the "Analyze Friendship" button.
The application simulates an analysis process.
A friendship score is generated.
Based on the score:
A friendship level is assigned.
A badge is displayed.
Visual effects may be triggered.
Friendship Levels
Score Range	Level
96 - 100	Legendary Friendship
81 - 95	Unbreakable Squad
61 - 80	Best Buddies
41 - 60	Good Friends
21 - 40	Casual Friends
1 - 20	Barely Know Each Other
